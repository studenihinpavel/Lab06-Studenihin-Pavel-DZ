# Домашнее задание к лабораторной работе №6

## Условие задачи

Написать программу, которая определяет, является ли введённый год високосным, и выводит количество дней в этом году.

Год считается високосным, если:
- он делится на 4 и при этом не делится на 100, **или**
- он делится на 400.

## 1. Алгоритм и блок-схема

### Алгоритм

1. Начало
2. Объявить переменную:
   - `year` — целое число (введённый год).
3. Запросить у пользователя ввод года.
4. Считать значение в переменную `year`.
5. Проверить условие високосности:
   - `(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)`
6. Если условие истинно:
   - Вывести: «Год N високосный, 366 дней в этом году».
7. Иначе:
   - Вывести: «Год N не високосный, 365 дней в этом году».
8. Конец

## 2. Реализация программы

```c
#include <stdio.h> 
#include <conio.h> 
#include <math.h> 
#include <locale.h>

int main()
{
    setlocale(LC_CTYPE, "RUS");
    int year;
    printf("Введите год = ");
    scanf_s("%d", &year);
    if ((year % 4 == 0) != (year % 100 == 0) || (year % 400 == 0))
    {
        printf("Год %d високосный\n", year);
        printf("366 дней в этом году\n");
    }
    else
    {
        printf("Год %d не високосный\n", year);
        printf("365 дней в этом году\n");
    }
    system("pause");
}
```
